# ✍️ Digital Signature Generator

A modern, professional **Digital Signature Generator** web app built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

![Digital Signature Generator](digital-signature-electronic.jpg)

---

## 🚀 Live Demo

> Open `index.html` in your browser to get started.

---

## ✨ Features

- 🖊️ **Live Signature Generation** — Type your name and see your signature in real-time
- 🎨 **Multiple Signature Fonts** — Choose from Classic, Elegant, Bold, Fancy, Modern, Cursive, Handwritten, Minimalist
- 🖌️ **Draw Signature Canvas** — Draw your own signature with mouse or touch support
- ↩️ **Undo / Redo** — Full undo and redo support on the drawing canvas
- 🌗 **Dark / Light Mode** — Toggle between dark and light themes
- 📥 **Multi-format Export** — Download as PNG, JPG, SVG, or Transparent PNG
- 🎨 **Color Picker** — Customize your signature color
- 📏 **Font Size Control** — Adjust signature size with a slider
- 💾 **Auto-save** — Signatures saved automatically using localStorage
- 🔔 **Toast Notifications** — Smooth feedback messages for all actions
- 📱 **Fully Responsive** — Works perfectly on desktop, tablet, and mobile
- 💎 **Glassmorphism UI** — Premium SaaS-style design with blur effects and gradients
- ✨ **Smooth Animations** — Hover effects, transitions, and floating elements

## 📦 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/devil970/digitalsignature.git
   ```

2. **Open the project**
   ```bash
   cd digitalsignature
   ```

3. **Run it** — Just open `index.html` in any modern browser. No build step needed!

---

## 🎯 How It Works

1. **Type Mode** — Enter your name in the text input → pick a font style → customize color and size → download
2. **Draw Mode** — Use your mouse or finger to draw a custom signature on the canvas → undo/redo as needed → download
3. **Export** — Choose PNG, JPG, SVG, or Transparent PNG format and download instantly
